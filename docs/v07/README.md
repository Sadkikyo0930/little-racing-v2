## 4. P0 结构修复摘要

1. **取消 V0.6 多层螺旋盘山路网**（高程 1–99 m 立体回环、视觉上悬空黑色「天路」），
   改为单层 2D 不自交、高程单调升→平→降的「穿山公路」。
2. `tunnelAt(x,z,y)` 由 2D 最近轴点判定升级为**严格 3D 体积判定**：按轴向线段插值，
   检查横向 `inLat`、轴向 `inAlong`、高程 `inY`，并返回带符号轴向进度 `u`
   （洞口前 `u<0`、出口后 `u>rings`）。
3. `drawRoad()` 只生成**一条连续路面**；`tunnelProfile()` 只生成侧壁与拱顶，不生成底部横面，
   彻底消除两层重叠路面。
4. 删除 V0.6 的 `clampIntoTunnel()`「吸车」逻辑，改为 `softTunnelGuide()`：
   车身半宽 `2.45 m`、洞壁余量 `0.9 m`、单帧修正限幅 `1.2 m`，不瞬移、不吸车；
   并在洞口前 18 环做**引道车道渐进收窄对准**，配合洞口前高程外插，
   解决斜向驶入时车辆在洞外横向偏出、进洞即穿壁的问题。
5. 三视角相机在洞内统一收进洞轴并强制钳制目标与结果；相机钳制只在严格 3D 洞内生效，
   **不靠限制相机掩盖车辆穿模**，车辆碰撞判定完全独立。

详见 `TUNNEL_FIX.md`。

  引道石砌挡墙与宝瓶护栏、弯道警告牌。
- **海滨小镇**：11 栋地中海民居、红瓦双坡顶、蓝百叶、条纹遮阳棚、门头招牌、
  花箱与阳台铁艺、喷泉小广场、入口石拱门、跨街彩旗、咖啡桌椅果摊、斑马线。
- **灯塔海崖**：红白条纹灯塔、玻璃灯室、铜顶、旋转光束、圆形石铺平台、宝瓶栏杆、
  五级台阶、石拱桥、层状海蚀岩、凉亭、帆船海鸥、Shader 海面。
- **湖畔区域**：Shader 水面（波纹 / 镜面高光 / 浅滩 / 泡沫）、3 圈浅滩、
  岸线顶点色过渡、560 颗卵石、300 簇芦苇、木栈道与栏杆、保留驼峰玩法。

材质与性能手段：9 类以上程序化 `CanvasTexture`（石材 / 沥青 / 鹅卵石 / 瓦 / 岩 /
灰泥 / 木 / 路缘 / 碎石）以及门头、纹章、遮阳棚、灯塔条纹贴图；
`MeshStandardMaterial` + PBR 近似参数、`MeshPhysicalMaterial` 玻璃；
`Batch` 按弧长 UV 合并 ribbon / quad；`optimizeDrawCalls()` 将同材质同基础几何的小 Mesh
合并为 `InstancedMesh`（13 组，省 91 次 Draw Call）；重复装饰全部实例化；
水面与天空为低开销 Shader / 预烘焙贴图。移动端按 UA 与视口降级：
`DETAIL=0.62`、`TEXSIZE=256`、较低 `pixelRatio`、无 antialias、较小阴影贴图。

**未使用 GLB / Blender / greamloop 模型**：本次全部为程序化几何 + 程序化纹理，
没有把效果图贴在背景上冒充 3D，所有主要建筑、道路、树木、灯塔、隧道均为可从不同角度观看的
实际三维结构。这一取舍需在真机性能与美术质量上继续评估。
