恢复流程：① 恢复前校验备份文件自身（每条 value 的 SHA-256 是否与记录一致 + 清单 manifestSha256 是否一致）→ 不通过则中止，不写入任何数据； ② 写入（自动跳过设备绑定等受保护键）；③ 恢复后校验逐键读回 localStorage 再算 SHA-256 比对 → 不通过则自动回滚到恢复前状态。 只有前后两次校验全部通过，才会显示「恢复成功」。旧版（含 computed-on-demand 占位符）备份不可恢复，请重新导出 v2.0 备份。

正式家庭数据重置须由家长在确认清理范围后，于孩子将要使用的设备（生日赛车 iPad 等）上手动执行本步。本工具不会自动连云、不会清空任何 CloudBase 表。

说明与边界

  • 本机赛车进度与 CloudBase（学习记录 52 条 / 家庭 little-growth-family-001 / 设备授权 / 1800 秒 md-1 计时 / 生日超跑“六星闪耀”）完全分离；本工具不发任何网络请求（无 fetch / XHR / CloudBase SDK），不读取也不修改云端，不修改 GitHub。
  • SHA-256 采用内嵌标准实现（与 Node / openssl 结果一致），不依赖 crypto.subtle，因此用 file:// 直接打开或 http 非安全上下文也能算出真实哈希。
  • 备份范围仅为本机赛车存档键；r5_device 等设备绑定 / 授权 / 设置键不进入备份、也不会被恢复覆盖，避免跨设备串号。
  • “生日限定超跑”由服务端在 2026-11-14 按可信时间自动发放，不在本地存档中，重置本地数据不会提前领取或删除它。
  • 不同设备各自独立：爸爸试玩若只在爸爸设备，孩子设备本就是全新；若爸爸曾在孩子设备试玩，则在该设备执行重置即可，无需碰其它设备。
  • 如无法确认某条记录属于“爸爸试玩”还是“孩子真实进度”，请勿整表清空；先导出备份，再单独处理可确认的项。
